# Arcade_Galaga — Basys 3 Porting Specification

Target: Digilent Basys 3 (`xc7a35tcpg236-1`), Vivado 2020.2, VHDL target language.

## 1. Upstream Source

- **Repository**: [darfpga/Arcade_Galaga](https://github.com/darfpga/Arcade_Galaga)
- **Original board**: Altera DE2 (50 MHz oscillator)
- **Core clock**: 18 MHz (video/slot machine), derived from 36 MHz via T-flip-flop
- **ROMs**: `galaga.zip` + `galagamw.zip` from MAME (dual-ROM set)

## 3. Build Workflow

### Step 1: `make setup`
- Sanity-checks key upstream source files
- Applies `scandoubler_fix.patch` to `mist/scandoubler.v`
- Applies `galaga_dipswitch.patch` to `rtl_dar/galaga.vhd`
- Runs `prep_roms.sh` to compile `make_vhdl_prom` and generate all PROM VHDL from ROM zips

### Step 2: `make clk_wiz`
- Creates `clk_wiz_0` MMCM IP stubs
- Real IP must be generated by Vivado (run in Vivado GUI or batch mode)

### Step 3: `make patch`
- Regenerates the Basys3 wrapper via `make_de10_lite_to_basys3_patch.sh`

### Step 4: `make synth`
- Resets `synth_1` run and launches synthesis
- Runs from `/tmp` to keep `vivado.log`/`vivado.jou` outside the repo

### Step 5: `make bitstream`
- Runs implementation + `write_bitstream`

## 4. Clock Architecture

```
100 MHz (clk, pin W5)
  └── clk_wiz_0 (MMCM)
        └── 36.000 MHz (clock_36)
              ├── /2 → clock_18 (18 MHz) → galaga core
              │        └── /2 → clock_9 (9 MHz) → PS/2 keyboard + kbd_joystick
              ├── mod-6 counter → clock_12 (12 MHz) → scandoubler clk_sys
              ├── mod-6 counter → clock_6  (6 MHz)  → scandoubler ce_x1
              └── VGA output process (registered)

Reset: btnC OR NOT mmcm_locked (core held in reset until MMCM locks)
```

## 5. DIP Switch Mapping

Switches are active-high (UP=1, DOWN=0). Selective inversion so that
all-down = factory defaults matching the original hard-coded values.

### dip_switch_a (game options)

| Bit | Switch | Mapping | Function |
|-----|--------|---------|----------|
| 7 | sw(12) | direct | Cabinet: UP=Upright, DOWN=Cocktail |
| 6 | — | tied to `'1'` | Unused |
| 5 | sw(11) | **inverted** | Test mode: UP=off (normal), DOWN=on |
| 4 | sw(10) | **inverted** | Freeze: UP=off (normal), DOWN=on |
| 3 | sw(9) | **inverted** | Demo sound: UP=off, DOWN=on (normal) |
| 2 | — | tied to `'1'` | Unused |
| 1 | sw(8) | direct | Difficulty MSB |
| 0 | sw(7) | direct | Difficulty LSB |

```vhdl
dip_switch_a => sw(12) & '1' & not sw(11) & not sw(10) & not sw(9) & '1' & sw(8 downto 7),
```

### dip_switch_b (lives/bonus)

| Bit | Switch | Function |
|-----|--------|----------|
| 7:6 | sw(6:5) | Lives |
| 5:3 | sw(4:2) | Bonus |
| 2:0 | — | tied to `"111"` (reserved) |

```vhdl
dip_switch_b => sw(6 downto 5) & sw(4 downto 2) & "111"
```

### Defaults (all switches UP)

Original hard-coded values: `dip_switch_a = "11110111"`, `dip_switch_b = "10010111"`.

## 6. Input Mapping

### PS/2 Keyboard (Somhi kbd_joystick interface)

| Key | Function |
|-----|----------|
| F3 | Add coin |
| F4 | Start 1 player |
| F5 | Start 2 players |
| F8 | Toggle display mode (31 kHz VGA / 15 kHz TV) |
| SPACE | Fire |
| LEFT | Move left |
| RIGHT | Move right |

Note: Galaga has no up/down movement — only left, right, and fire.

### Joystick (JA Pmod, active-low)

| JA Pin | Function |
|--------|----------|
| JA1 (J1) | Right |
| JA2 (L2) | Left |
| JA3 (J2) | Down (not used by core) |
| JA4 (G2) | Up (used with fire for combos) |
| JA7 (H1) | Fire |

Combo mappings (OR-merged with keyboard):
- Coin = Fire + Up
- Start1 = Fire + Left
- Start2 = Fire + Right

## 7. VGA Output

- 12-bit VGA (4 bits per R/G/B channel)
- Scandoubler: MiST `scandoubler.v` (patched in-place by `scandoubler_fix.patch`)
- Input: core's 3/3/2-bit RGB padded to 6 bits by MSB replication; forced black during blank
- Output: 31 kHz VGA (scan-doubled 15 kHz core output)
- F8 key toggles display mode:
  - Default (F8 off): 31 kHz scan-doubled VGA
  - F8 on: 15 kHz TV (native core RGB, composite sync on HS, VS held high)

## 8. Audio

- 10-bit audio from `galaga` core (sum of MB88 54XX channels + Namco WSG)
- PWM accumulator clocked at 18 MHz (same as core)
- Output via PmodAMP2 on JC Pmod: AIN (JC1), GAIN (JC2, sw15), SHUTDOWN (JC4, sw14)

## 9. Patches Required

### Scandoubler Fix (`contrib/code/scandoubler_fix.patch`)
- **File**: `mist/scandoubler.v` line 124
- **Change**: `sd_buffer[2*2**HCNT_WIDTH]` → `sd_buffer[0:2*2**HCNT_WIDTH-1]`
- **Reason**: Vivado Verilog parser rejects Altera-style unsized array declarations
- Applied in-place during `make setup`

### DIP Switch Promotion (`contrib/code/galaga_dipswitch.patch`)
- **File**: `rtl_dar/galaga.vhd`
- **Change**: Promotes `dip_switch_a` and `dip_switch_b` from hard-coded internal signals to entity-level input ports
- **Reason**: Allows the top-level wrapper to drive dip switch values from physical switches
- Applied during `make setup`

### Basys3 Wrapper (`contrib/basys3/code/galaga_de10_lite_to_basys3.patch`)
- **Base**: `rtl_dar/galaga_de10_lite.vhd` (DE10-Lite wrapper, diff reference only)
- **Target**: `basys3/arcade_galaga_basys3.srcs/sources_1/new/arcade_galaga_basys3.vhd`
- Generated by `make_de10_lite_to_basys3_patch.sh` during `make setup`
